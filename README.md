<h1 align="center">Ding</h1>
<p align="center"><strong>钉住消息和隐私</strong></p>
<p align="center">面向钉钉的第三方 Xposed 模块 · libxposed API 102 · Material Design 3</p>

Ding 提供消息防撤回、禁止已读上报和隐藏输入状态等功能。

[反馈问题](https://github.com/comewhy/com.comewhy.Ding/issues) · [Telegram 频道](https://t.me/come_why)

## 功能

| 功能 | 说明 |
| --- | --- |
| 消息防撤回 | 尝试保留本机已经收到、仍可读取的他人普通聊天消息，并在气泡下方显示撤回标签。 |
| 禁止已读上报 | 拦截本机普通聊天的已读回执，同时更新本地阅读状态。 |
| 隐藏输入状态 | 拦截本机发送的“正在输入”状态，正常文字发送照常。 |
| 独立开关 | 三项功能分别设置；保存后重启钉钉生效。 |

禁止已读上报针对普通聊天，不覆盖 DING、审批、文档查看等独立业务状态；其他设备产生的回执仍会生效。

## 安装与使用

1. 从 [Releases](https://github.com/comewhy/com.comewhy.Ding/releases) 获取已发布的 APK 并安装。
2. 在 LSPosed 中启用 **Ding**，勾选 **钉钉** 作用域。
3. 打开 Ding，确认框架连接状态，按需要设置功能开关。
4. **强行停止钉钉，再重新打开**，使模块和新设置生效。

更新模块或修改开关后同样需要重启钉钉。设置页的框架连接状态不等于聊天功能已经生效，建议先用测试账号验证。

## 撤回标签

标签独立显示在消息气泡下方，不拼接到原消息正文中。

| 标签 | 含义 |
| --- | --- |
| 已被撤回 · 本机已保留 | 原文本或完整本地附件已确认可用。 |
| 已被撤回 · 仅保留预览 | 图片只有本地预览，无法确认完整原图。 |
| 已被撤回 · 附件未缓存 | 图片或语音的本地附件无法确认可用。 |
| 已被撤回 | 混合富文本仅确认撤回事件，不宣称其全部附件已保留。 |

- 防撤回无法恢复模块运行前已经被清除的正文。
- 模块不额外下载或永久备份附件；缓存被清理后，附件可能无法显示。
- 关闭防撤回并重启钉钉后，历史标签暂时隐藏；再次开启后恢复。
- 撤回元数据按账号、会话及消息 ID 隔离，保存在钉钉的专用私有数据库中。清除钉钉应用数据会清除这些记录。
- 标签统一使用“已被撤回”，不据此推断撤回执行者；群管理员也可能撤回消息。
