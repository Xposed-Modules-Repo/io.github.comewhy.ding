## 功能

设置首页按「消息与隐私」「聊天与媒体」「提醒与自动化」「定位与设备」「界面与外观」「高级与网络」六类组织，配置备份、更新和应用入口集中在底部「模块设置」。二级列表中点击功能文字编辑参数，右侧开关负责启停；记录与收藏等管理入口不额外增加开关。条目较多的分类采用三级结构：先进入功能组，再选择具体功能；「聊天与媒体」和「模块设置」保持二级。搜索仍直接定位具体功能或字段。「自动抢红包」在「提醒与自动化」中直接打开设置页，不再增加同名中间菜单。「解除截图限制」位于「消息与隐私 → 已读与通知隐私」；「隐藏「+」菜单项」「跳过启动页」直接位于「界面与外观」，「平板模式」直接位于「定位与设备」。

消息防撤回、修改聊天记录、消息归档与检索、关键词提醒、虚拟定位、Wi-Fi 伪装将相关操作显示为同一卡片中的子行。撤回记录位于消息防撤回卡片内，修改记录位于修改聊天记录卡片内，归档保留期位于消息归档卡片内；撤回与归档继续分别管理保留期。Wi-Fi 列表只有「WiFi 参数」行及主开关，扫描选项位于参数弹窗的「同时替换扫描列表」。点击子行文字打开对应编辑器或管理页，点击开关控制功能；卡片标题不增加详情导航。关闭功能保留参数，关闭防撤回后仍可进入记录管理页。

可点击条目右侧使用带文字的圆角入口：分类和功能组显示「进入」，参数显示「设置」，记录或说明显示「查看」；导入、导出、检查更新和打开模块管理器显示对应动作。搜索纯开关显示「定位」。点击文字区域或右侧入口执行相同操作，开关独立控制启停；入口颜色随深浅主题和强调色调整。「重启钉钉」位于保存成功后的底部提示条，不是独立设置菜单。

首页「功能设置」顶部支持本地搜索功能名、常用别名和重要子设置，例如“已读”“步数”“截图”“保留期”。点击纯开关结果会定位并高亮对应行，点击参数结果会打开编辑器并定位字段；返回后保留搜索词和滚动位置。搜索不读取聊天内容、不保存历史，也不修改配置。未连接框架时仍可浏览和搜索。

BLE、步数、Wi-Fi、蓝牙和设备标识等设置独立编辑保存；地点收藏与地图 Key、照片替换参数也分别保留草稿。页面重建不会自动保存，编辑内容按对应入口的确认操作提交。若编辑期间框架连接或应用进程发生变化，草稿保留供查看和复制，需取消后重新打开设置再保存。

| 配置备份 | 通过系统文件选择器导出／导入配置；支持旧版备份迁移，保存后读取框架值确认结果。 |

| 修改聊天记录 | 在普通纯文本消息的长按菜单修改该条气泡的本机显示；对方、服务器消息、会话预览和通知保持原文。支持修改记录管理、恢复原文和删除，默认关闭，详见下方使用边界。 |

## 自动抢红包

进入「提醒与自动化 → 自动抢红包」直接打开设置页。开启总开关后，单聊和群聊范围仍可分别控制；“抢自己发出”默认关闭，只有同时打开总开关和该选项才会尝试领取本人发出的红包。会话黑名单按用户名、聊天标题或完整会话 ID 匹配，发送人黑名单按名称或 UID 匹配，均为去除两端空白后的完整匹配。

领取入口使用钉钉 9.0.5（versionCode 1280）的原生红包状态查询和领取服务，不依赖自动已读或媒体状态上报，也不会为领取而打开聊天。钉钉进程运行并登录时监听新消息；钉钉退出、重启或重新连接后，补收本地可访问且消息时间在最近 24 小时内的红包。补收包含开启前、总开关关闭期间和已读消息，但仍遵循当前单聊／群聊开关及黑名单；整 24 小时及更早的消息不再发起新的领取流程。

普通、拼手气和当前账号符合条件的专享红包会进入原生领取流程。本人已领取、红包已领完、过期或无资格不会伪造成功；口令、视频、炸弹和其他需要人工操作的红包会跳过。领取结果不明确时先查询服务端状态，确认金额后才显示成功提示。多笔成功按完成顺序逐笔显示“抢到红包 X.XX 元”；补收中的已领完或失效红包会等待本批次未完成任务结算，再合并显示“错过 n 个红包”。

模块只保留任务去重、待核验和未显示提示所需的本地状态，不在设置页提供领取记录或历史金额列表。首次启用或更新模块后请彻底退出并重新打开钉钉，使新 Hook 和补收入口加载。

进入「提醒与自动化 → 回复与消息」，可以分别开启普通已读和媒体自动上报。除实时新消息和离线未读补收外，钉钉启动后及收到聊天通知时还会触发本地未读补扫，因此此前已存在、仍在本地缓存中的未读消息也可能上报。补扫跳过已读消息，不主动向服务端翻页拉取历史。媒体仅提交状态，不启动播放器、查看器或下载附件。支持图片 `2`、语音 `3`、普通文件 `4`、视频 `103/202` 和通过原生资格检查的钉盘文件 `500/501/502/506`；鉴权、加密、阅后即焚、文件夹、空间链接及未建立独立回执链的富文本附件暂不处理。

有效开启任一自动回执类型并重启钉钉后，钉钉首页「+」菜单提供「一键已读」。点击并确认后，按当前有效开启的回执类型执行同样的本地未读补扫；未开启的类型不会因此启用。本功能不打开聊天页面，也不以清除本机未读角标为目标。每轮最多检查 200 个会话、每会话 200 条消息、总计 2000 条消息，结果还取决于本地缓存和原生回执接口，不能保证所有未读均已提交或被服务端受理。

自动上报与聊天状态隐私按类型互斥，但**不会自动关闭对方的开关**：开启其中一项时，若同类型冲突项仍在生效，会弹窗说明冲突并引导你前往对应设置手动关闭，本次开关保持原状。隐私总开关关闭时保留的子选项不构成有效冲突，重新开启总开关时按选择的类型处理。自动上报开关的 Hook 在钉钉启动时安装，保存后需强行停止并重新打开钉钉才会生效；运行状态会显示“待同步/重启”，重启后显示“正在监听符合条件的新消息”。运行状态分别显示待提交、提交中、服务端已受理、失败和结果未确认，只有匹配的原生成功回调才计为服务端受理；发送端显示需另行实测。切号、同账号重新登录、关闭功能或卸载 Hook 会取消旧任务。成功去重记录按账号、完整会话 ID、消息 ID 和回执类型保存在私有数据库。

旧“自动已读”及其日志开关已经退休，原值不自动开启新功能。导入旧版配置时两个新开关的处理规则见[安全正则与配置备份](#安全正则与配置备份)。

## 聊天状态隐私与排除名单

聊天状态隐私覆盖普通聊天已读以及支持的语音、图片、视频和普通链接播放/点击上报，不覆盖 DING、审批、文档查看等独立业务状态；其他设备产生的回执仍会生效。

进入「消息与隐私 → 已读与通知隐私 → 聊天状态隐私」，可以分别选择“拦截普通已读”和“拦截播放与点击”。总开关关闭后保留子选项，重新开启时恢复；子选项全关时总开关同步关闭，此后直接开启总开关会默认同时开启两项。旧版全关、仅已读、仅播放、全部开启四种组合逐一保留，既有默认值不变。

普通已读可选“始终拦截”或“回复后已读”；后者只在成功回复后补报此前符合条件的普通已读。**播放与点击不会因回复而补报**，不建立历史媒体回执队列。

**排除名单（黑名单）由两类状态共享**。沿用旧白名单数据及备份，名单内的普通已读和播放/点击都恢复钉钉原有流程；名单外仍按子选项处理。这是合并后的明确变化，不会主动补发升级前被拦截的状态。

| 设置状态 | 名单内 | 名单外 |
| --- | --- | --- |
| 总开关关闭 | 两类状态均使用原生流程 | 两类状态均使用原生流程 |
| 总开关开启，排除名单启用且命中 | 两类状态均使用原生流程 | 普通已读按所选模式；播放/点击开启时始终拦截 |
| 总开关开启，排除名单关闭或为空 | 没有例外放行 | 按已启用的子选项处理；未启用项使用原生流程 |

- **单聊**：可填写消息显示的用户名称、聊天标题或完整会话 ID。备注名与昵称不同时，优先填写消息旁实际显示的发送者名称；如要限定某一段单聊，使用完整会话 ID。
- **群聊**：可填写群名、消息发送者名称或完整群会话 ID。群名或会话 ID 匹配对应会话，发送者名称按当前消息匹配；只影响本机产生的回执，不会改变其他群成员的设置。
- **匹配**：名称、标题和会话 ID 均按大小写敏感的完整文本匹配，不支持前缀、通配符或正则，也不会自动把手机号或用户 UID 转换成会话 ID。名称可能重复或变化，同名可能同时命中；需要精确限定会话时使用完整会话 ID。当前编辑器通过逐行输入维护名单。
- **格式与维护**：每行一个名称或会话 ID，忽略空行、去除两端空白并精确去重；最多 50 项，每项 200 个 Unicode 字符，允许名称中的普通空格，拒绝控制字符、格式字符和无效 Unicode 字符。删除对应行移除单项；“整理名单”规范格式，“清空”只清除草稿。点击确定才保存，取消不修改配置；关闭名单仍保留内容。
- **无效数据**：保存或导入遇到无效名单会整批拒绝，不截断或只应用部分条目。已有无效名单保留原文供修正，修正前整批不放行。无法离线验证名称或 ID 是否真实存在，合法但不存在的条目不会匹配。
- **账号与设备**：名单属于本机模块的全局配置，不按钉钉账号独立保存；切换账号需复核。保存后重启钉钉再验证，只影响今后本机产生的回执，不能撤销已发状态，其他设备仍可能上报。
- **适用范围**：排除名单同时放行普通已读、语音“已收听”和支持的图片/视频/链接状态；DING、审批、文档等独立业务不在此范围。

编辑器内的“填写规则”提供同样说明；旧“禁止已读上报”“拦截播放与点击上报”和名单别名仍可搜索到对应子设置。菜单摘要只表示配置范围，运行状态另行核验：只有宿主状态新鲜且配置指纹一致时才显示已生效；部分安装、待同步/重启、未确认分别提示。

## 设置生效与后台运行

多数 Hook 开关和初始化参数在钉钉启动时读取，更新模块或修改这些设置后需要重启钉钉。保存成功后的底部提示条提供「重启钉钉」：未检测到运行中的当前模块主进程时直接打开钉钉；检测到时通过控制通道请求钉钉主进程自行退出，再重新打开。这条快捷路径无需为 Ding 额外授权 ROOT，也不等同于系统对整个应用包执行“强行停止”。若配置仍未采用，或钉钉还在运行旧模块，请从系统应用设置强行停止后再打开。

主题色、隐藏桌面图标等模块本机设置无需重启钉钉。已开启 BLE 后保存参数会在下一次扫描时读取；首次开启仍需重启安装 Hook。定时任务的新建、编辑、暂停和删除由本机任务库管理，宿主每次执行前读取最新状态，无需每改一条任务就重启；定时消息功能开关首次开启仍需重启。原图选项的日常记忆也无需重启。

设置页无需一直打开，已加载的 Hook 在钉钉进程内运行。定时发送需要钉钉主进程运行、对应账号已登录且消息通道可用；进程停止期间不会发送。恢复后只补发原计划时刻之后 10 分钟宽限内的任务，超过宽限的标记过期；该窗口从原计划时刻计算，不从恢复运行时重新计时。

当前兼容性卡展示钉钉版本的验证情况与 Android 支持范围；框架卡展示连接与作用域状态。这些信息不能代替实际 Hook 加载结果。运行状态查询主要面向钉钉主进程，收到系统通知只说明推送链路可用，不能据此确认主进程及所有模块功能正在工作。请结合具体功能的运行状态和实际效果验证，运行错误可通过模块日志排查。

关键词提醒需要钉钉的系统通知及对应通知渠道开启。临时投递错误会有限重试；身份暂不可识别时采用会话内去重。正常发送确认仍在无法显示窗口时自动放行；确认期间账号、目标或内容发生变化时，该过期请求会取消并提示重新发送。

关键词可以用中文逗号 `，`、英文逗号 `,` 或换行分隔。进入「提醒与自动化」，点击「关键词提醒」文字区域可选择提醒方式：“关键词提示”显示“发送者-消息触发关键词：关键词”；“消息通知”显示发送者和消息内容，并可点击进入对应会话。修改后强行停止钉钉并重新打开，使新设置生效。

关键词铃声保留默认铃声、静音和自选系统铃声。点击“浏览”打开系统铃声选择器，页面显示铃声名称，点击保存并经框架读回确认后生效；取消选择或退出未保存不会修改配置。不提供手填 URI、本地音频浏览或应用内振动设置，也不会修改手机的系统默认铃声。振动由系统通知设置控制；旧备份的振动字段兼容忽略。

## 安全正则与配置备份

正则使用 [RE2/J 1.8](https://github.com/google/re2j)，一行一条，最多 50 条、每条 100 字；普通关键词继续使用原有逗号、分号和换行分隔。正则按精确文本去重，`\S` 与 `\s`、含逗号的量词不会被合并或拆分。匹配在有界后台队列执行，不在宿主消息插入线程运行；过载时该次提醒可能被跳过并记录错误。

安全正则不支持前后查找、反向引用、字符类交集和嵌套有界重复，并限制分组深度、编译展开及匹配文本长度。`\w`、`\d`、`\s` 和单词边界采用 RE2/J 的 ASCII 规则，Unicode 大小写行为也可能与旧引擎不同。所有旧引擎正则会先暂停、保留原文；在关键词或高级设置中阅读说明、勾选确认并保存，通过校验后才生效。不兼容条目会列出原因，不会退回旧正则引擎。

备份输出格式为 **schema 3，兼容读取 schema 1/2**。旧版备份导入时会关闭两个新自动回执开关；新版备份存在同类型自动上报与隐私保护的有效冲突时整份拒绝。旧规则列表仅按旧分词规则迁移一次，不会猜测拼回旧版已经拆坏的表达式；旧正则恢复后仍需确认迁移。已移除功能的已知旧字段会按原类型校验后忽略，其他未知字段、重复字段、非法值、损坏 JSON 和尾随垃圾会拒绝。导入上限为 1 MiB；空字符串可以恢复无关键词和默认铃声。导入成功以框架权威读回为准，取消已提交操作不代表回滚。

配置 JSON 只包含功能开关和参数，不包含定时任务内容、撤回或归档正文、本机改文记录和附件。照片配置中的路径或 URI 可以作为参数导出，但照片文件和访问授权不在备份内，换机或重装后需要重新选择照片。消息归档页的 HTML／JSON 导出是当前检索结果的单独导出，不属于配置备份。

## 修改聊天记录

开启「聊天与媒体 → 修改聊天记录」并重启钉钉后，在普通纯文本消息上长按，选择「修改聊天记录」。修改只绑定当前账号、当前会话中的那一条消息，仅改变本机气泡显示；相同内容的其他消息、会话列表、通知、服务器消息和对方设备保持原文。系统、公告、机器人、富文本、引用、卡片、链接、媒体及已撤回消息不在支持范围。

首次编辑保存原文快照，后续可再次编辑。卡片中的「修改记录」入口可搜索和管理当前账号的改文，支持恢复原文、删除单条和清空当前账号；恢复原文会删除对应改文记录，清空与撤回记录、消息归档分别管理。功能关闭或连接断开时，模块可查看已取得的只读镜像，并提示可能过期；写操作需要可用的宿主控制通道。原消息变化或撤回后，旧改文可能失效，不能将本机记录当作服务器消息备份。

## 密聊文本留存

「消息与隐私 → 撤回与本地记录 → 密聊文本留存」默认关闭。开启并重启钉钉后，仅在钉钉成功解密非本人发送的密聊消息时保存文本，供防撤回及消息归档检索使用；不复制图片、语音、文件等附件，也不阻止原消息按原规则焚毁。它不放行密聊创建权限或服务器会员校验。

留存文本保存在钉钉本机私有归档库中，按归档保留期处理；「清除当前账号记录」会一并清理该账号的归档和密聊文本。清除钉钉应用数据或卸载钉钉会删除这些本机资料，配置备份不包含正文。

## 自动回复边界

自动回复只处理可确认账号的实时新消息，不处理历史拉取、离线补收和重连批次。默认回复模式继续使用关键词、非工作时间、所有新消息等触发条件（任意命中），时间段使用手机时区；匹配回复模式只使用用户维护的规则，固定模式的内容会折叠并保留。

匹配规则一行一条，格式 `AA-BB`：消息包含 AA 时回复 BB，忽略触发词大小写。按第一个半角减号分隔，回复允许包含减号；最多50条，触发词100字、回复200字，重复触发词会拒绝保存。多条同时命中时只使用最上面一条，规则模式不会因固定模式的“所有新消息”等开关而回复未命中的消息。

同一会话回复间隔可拖动设置为0～30分钟，旧配置默认5分钟。0表示取消时间间隔限制，每条符合模式和范围的新消息均可回复；本人、历史、重复消息及回复回显保护仍然保留。会话范围对两种模式共用。群聊 @ 范围需要 SDK 确认提及当前账号，且完整正文含当前昵称；纯文本伪 @、转发和仅 @ 全员不触发。

登录、退出、被踢下线以及发送前身份变化会取消未提交任务；真正发送使用当前账号的会话和宿主消息工厂。保护范围到模块交给原生 SDK 的边界，SDK 接管后的网络发送不能由模块事务撤销。

## 个性主题与装扮中心

在 Ding 设置页「界面与外观 → 主题与水印」开启并保存「个性主题」，重启钉钉后点击该条目的「打开」即可进入钉钉装扮中心。钉钉未运行时会尝试直接启动并进入装扮中心；已运行时通过宿主受控入口打开。该项也曾称「个性装扮破解」，设置键与已有备份继续兼容。若入口失败，请检查当前模块是否已加载，并优先在已验证的钉钉 9.0.5／1280 上复核；其他版本可尝试，但不保证路由与功能可用。

普通主题沿用钉钉的本机选择、应用和保存流程，按实际主题属性处理，不依赖栏目名称或固定分类列表；节日、影视及后续动态栏目中的普通主题使用同一流程。AI 主题、企业专属和专业主题继续使用原生限制。

一键装扮、动态／AI 头像和个性资料页使用集中处理的本地装扮权益判断，覆盖已核实的原生入口与装扮权益查询；新增栏目复用相同调用时可随之覆盖。它不修改全局会员状态，也不把 AI 生成、训练、上传或保存的服务器失败改成成功。新的权益接口或不同调用路径仍需适配，不能保证未来所有会员窗口自动可用。Android App 图标仍遵循钉钉原生的平台限制。

用户已真机自测确认普通个性主题和节日、影视栏目成功；一键装扮、动态／AI 头像、资料页封面的实际生成、应用、云端保存与他人端展示需要分别验收。主题清单和资源可用性取决于宿主配置与下载结果；未缓存资源下载、冷启动恢复、深浅模式切换及其他设备也需分别记录结果。设置需要可用的远程配置服务，免 ROOT 框架的实际行为尚待验证。

## 原图发送偏好

在设置页开启「原图发送偏好」，点击卡片选择模式：

- **默认原图**：每次从普通聊天打开照片选择器时，默认勾选“原图”；本次仍可手动取消。
- **记住上次选择**：使用当前钉钉账号上次在选图器确认提交图片时的“原图”选项；第一次没有记录时默认不勾选。取消选图、空结果、仅视频和选图期间切换账号不会更新记忆。

模块仅调整选择器初始选项，不修改照片或强制改变最终发送质量。记忆在选图结果有效返回时保存，不以图片最终上传成功为条件；之后取消发送确认不会撤销这次选图偏好。

功能默认关闭，关闭时使用钉钉原有行为。保存模块设置后需强行停止钉钉并重新打开；日常选图产生的记忆无需重启。只记录按账号隔离的原图布尔选项，不记录图片内容或路径；清除钉钉应用数据也会清除记忆。当前适配普通聊天的新旧选图入口，文件助手、头像、独立拍摄和转发入口不在本功能范围。

钉钉相册的“原图”是原生共享选项：同一相册内选择视频时，也会按钉钉原生规则影响视频清晰度，实际行为取决于宿主支持情况。仅视频选择不会更新模块记忆；包含照片的混合选择会记住该次选项。

## 平板模式

只在其中一台手机开启「平板模式」，让该手机以平板身份登录，另一台保持普通手机模式。设置页点击卡片可查看使用方法。

保存后，**强行停止钉钉并重新打开，再重新登录同一账号**。已有登录会话不会自动切换身份；关闭平板模式后也需重启并重新登录，以恢复手机身份。

本功能默认关闭，已验证适配依据为钉钉 9.0.5（1280），其他版本可尝试但不保证有效。双设备能否同时在线取决于钉钉服务端的账号与设备限制；本说明不代表已经完成两台手机同时登录的实测。

## 隐藏桌面图标

设置页提供「隐藏桌面图标」开关，开启后可隐藏桌面图标，模块功能不受影响。之后回到设置页的方式：

- 打开 **LSPosed → 模块 → 长按 Ding → 打开**；
- 或连接电脑执行 `adb shell am start -n io.github.comewhy.ding/.MainActivity`；
- 免ROOT框架用户可从框架管理器的模块列表直接打开。

在设置页关闭该开关即可恢复图标。覆盖安装更新会保留隐藏状态；全新安装默认显示图标。

若隐藏后桌面仍显示 Ding 图标，请关闭 LSPosed → 设置 →“强制显示桌面图标”，然后重新切换隐藏开关。

## 撤回标签

标签独立显示在消息气泡下方，不拼接到原消息正文中。

| 标签 | 含义 |
| --- | --- |
| 已被撤回 · 本机已保留 | 原文本或完整本地附件已确认可用。 |
| 已被撤回 · 撤回时已保留 | 撤回时已确认本机保留，但现在无法重新验证（原内容不可访问）。 |
| 已被撤回 · 仅保留预览 | 图片只有本地预览，无法确认完整原图。 |
| 已被撤回 · 附件未缓存 | 图片或语音的本地附件无法确认可用。 |
| 已被撤回 | 混合富文本仅确认撤回事件，不宣称其全部附件已保留。 |

- 防撤回无法恢复模块运行前已经被清除的正文。
- 模块不额外下载或永久备份附件；缓存被清理后，附件可能无法显示。
- 关闭防撤回并重启钉钉后，历史标签暂时隐藏；再次开启后恢复。
- 撤回元数据按账号、会话及消息 ID 隔离，保存在钉钉的专用私有数据库中。清除钉钉应用数据会清除这些记录。
- 标签统一使用“已被撤回”，不据此推断撤回执行者；群管理员也可能撤回消息。

## 撤回记录管理

管理操作需钉钉主进程运行、账号可识别。统计中的记录数量属于当前账号，数据库总占用包含其他账号及可复用空间。

默认永久保留。选择 30 天或 90 天时，确认后按首次观察时间清理当前账号的过期记录；手动清理也只作用于当前账号的模块元数据。清理不会删除原聊天消息或附件，但相应历史撤回标签无法恢复。删除记录后数据库文件未立即缩小属于正常空间复用。

## 免ROOT框架

Ding 可通过提供 libxposed API 102 的免ROOT框架（NPatch、FPA）加载，无需设备 root 或安装 LSPosed。加载、配置服务和具体功能仍取决于框架实现，不代表所有功能均已在这些框架上验证。

除上述两个框架外，使用其他免ROOT框架时需自行测试是否兼容——模块基于标准 libxposed API 102，理论上可被任何支持该 API 的框架加载，但未经验证。

### 两种加载模式

| 模式 | 说明 | 设置页 |
| --- | --- | --- |
| **远程加载**（推荐） | Ding 模块 APK 单独安装到手机；框架修补钉钉时从已安装的模块 APK 路径加载代码，模块与框架通过 XposedService 通信 | 有独立设置页，远程配置服务可用时可以保存功能开关和参数 |
| **嵌入模式**（NPatch） | 模块代码在修补时打包进钉钉 APK 内部（`assets/npatch/modules/`），通常没有独立 Ding 桌面入口 | 能否编辑配置取决于框架是否提供设置入口和远程配置服务；需要完整设置页时推荐远程加载 |

### 远程配置不可用时的默认行为

无论采用哪种加载模式，钉钉端读取不到框架远程配置时，都会使用基础默认配置：

- 消息防撤回开启。
- 聊天状态隐私默认仅拦截普通已读；播放／点击拦截默认关闭。
- 隐藏正在输入开启。
- 其余可选功能默认关闭；实际 Hook 是否可用仍取决于宿主接口和框架。

嵌入模式如没有可用的设置入口和远程配置服务，便无法通过当前模块设置页配置其他功能。需要自定义功能时，请单独安装 Ding 并使用提供远程配置服务的加载方式。独立设置页在框架未连接时仍可浏览和搜索，但不能保存需要框架的配置。

### 使用步骤（远程加载模式，推荐）

1. 安装 Ding 模块 APK 到手机（跟普通 App 一样安装）
2. 安装 NPatch Manager 或 FPA 到手机
3. 使用框架管理器修补钉钉 APK，加载模式选择**远程加载**
4. 在框架管理器中启用 Ding 模块、勾选钉钉作用域
5. 安装修补后的钉钉 APK
6. 强行停止钉钉（如已运行）并重新打开

桌面点击 Ding 图标即可进入设置页；高级设置需要框架远程配置服务可用。

### 兼容性说明

- 模块使用标准 libxposed API 102 声明（java_init.list + module.prop）；框架需要实际实现相应加载与服务接口。
- 可加载标准 API 102 模块不等于全部功能已验证，具体支持取决于框架实现和宿主版本。
- 高级设置、配置导入与导出需要框架提供可用的 XposedService 远程配置服务，并通过权威读回确认。
- 远程配置不可用时，设置页明确显示不可用并禁止高级设置保存；钉钉端使用基础默认功能。宿主私有 SharedPreferences 不是跨进程配置同步方案。

当前框架功能限制如下。表中“可尝试”仍要求对应 Hook 和宿主接口可用，不代表已经通过该框架的真机验收。

| 功能范围 | 受支持的 LSPosed | NPatch／FPA 等免 ROOT 或未知框架 |
| --- | --- | --- |
| 消息与隐私、聊天与媒体、提醒与自动化 | 可尝试 | 可尝试；配置与管理操作还取决于框架远程配置和控制通道 |
| 平板模式 | 可尝试 | 可尝试；仍受登录与服务端设备策略限制 |
| 虚拟定位、地图与收藏配置、轨迹模拟、高精度 GPS | 可用配置入口并尝试对应 Hook | 当前不开放这些配置入口，不尝试相应定位 Hook |
| Wi-Fi、蓝牙、BLE、基站、传感器、计步伪装 | 可尝试 | 当前不支持 |
| 设备标识与模板、显示旋转偏移、拍照替换 | 可尝试 | 当前不支持 |
| 反检测、隐藏 Root、隐藏调试状态、隐藏 Hook 框架、隐藏 VPN 状态 | 可尝试 | 当前不支持 |
| 模块主题色、桌面图标、版本与更新信息 | 无需钉钉进程常驻；部分配置仍需框架连接 | 同样以模块页面及框架服务实际可用性为准 |

这些限制由当前模块对框架能力的判断决定；在手机上单独给 Ding 授予 ROOT 不会自动使免 ROOT 框架支持表中功能。
